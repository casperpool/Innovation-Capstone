# Innovation-Capstone

This is the readme for my Innovation Capstone Project

## Why This Project
TFT players currently track personal comps and notes in scattered spreadsheets or notes 
apps, which is clunky for quick reference mid-game or sharing with others. Existing tools 
offer community or pro rankings, but nothing lets players build and organize their own 
customizable comp notes specifically for TFT.

## Goals
- [ ] Let players record and organize their own comp notes
- [ ] Make notes quick to reference during matches
- [ ] Support sharing notes/comps with others
- [ ] Stay flexible/customizable rather than prescriptive

## Roadmap
- **WK5–6:** Scoping & setup
- **WK7–8:** Core build (entering/saving comps, viewing notes)
- **WK9:** First prototype + early feedback
- **WK10:** Iterate on feedback, add secondary features
- **WK11:** Broader testing across skill levels
- **WK12:** Polish & wrap-up
